### `~/thehouseisonfire`

Rust developer interested in **systems programming, networking, protocol design and performance**.

Currently working extensively with the **MQTT ecosystem in Rust**, with an emphasis on robust APIs, protocol correctness, performance, and keeping abstractions as cheap as they ought to be.

Also build for the web with **TypeScript, React and Vue**. Former competitive programmer; still particularly fond of algorithms, data structures, and problems where knowing what the machine is actually doing matters.

Daily driving **Arch Linux + Hyprland + Fish**.
